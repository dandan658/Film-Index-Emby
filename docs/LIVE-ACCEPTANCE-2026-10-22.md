# 2026-10-22 在线验收

环境：用户授权的 Linux x64 Docker Emby 4.10.1.0，已安装插件 0.1.0.0。
以下记录不包含服务器地址、凭证、账号或媒体文件清单。

## 已实际验证

- 插件加载和通用设置页、设置保存及恢复。
- 简繁体检索、子串检索、媒体库/集数统计、日志倒序开关。
- 无登录请求被拦截，工作节点对非许可路径/主机拒绝探测。
- Linux 工作节点实际调用 FFprobe，读取云盘挂载视频的 3 条媒体流。
- 模拟原生播放开始、进度和停止事件，完成后标记此前未看完的集数；收藏、未开始和后续集状态保持正确。
- 元数据锁定及恢复。
- 清理媒体信息后原生定向刷新能重新探测，恢复音视频流和时长。

测试用设置、路径许可、收藏、播放进度和锁定状态已恢复。媒体视频文件未删除。

## 发现并在源码修复

1. 最爱提取查询缺少递归，漏掉库/剧/季目录下面的视频；提取与持久化查询均补上递归。
2. 倒序逻辑覆盖客户端明确请求的升序，但默认无排序查询不生效；改为只在未指定排序时提供默认倒序。

修复加入隔离 Emby 实例的回归测试，138 项检查通过。线上仍是旧 DLL，必须替换并重启后复测；不能把本地修复算成线上已生效。

## 环境问题与限制

- 云盘媒体目录只读，默认写视频旁的媒体信息 JSON 失败。应配置可写、持久化的 JSON 根目录。
- 原生日志发现内嵌封面格式声明不符，FFmpeg 被映射到封面流后截图失败，属于原生截图链路问题。
- 未配置远程工作节点的 URL/凭证，无法验收真实的双节点分布式链路。
- 缺少相应光盘、音乐、外部音轨测试素材，相关功能不能记为线上通过。
- 在线字幕下载、外部通知、豆瓣/IntroDB 的真实外部服务数据、跨客户端交互尚未完成端到端验收。
- 本次原生播放事件测试不代表浏览器、电视或 Infuse 的实际音视频播放测试。

仍不能宣称所有目标功能已经实现或全部验收通过。远程 HTTP ISO/DVD 等原有未完成项未因此改变。
