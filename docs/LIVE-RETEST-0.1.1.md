## 新修复：0.1.2-preview.1

1. 默认倒序：上版仅处理内部无排序查询，真实 HTTP 路径在到达查询前已被原生补入升序。现在在读取原始 HTTP 请求的查询构建层设置默认值，仍保留客户端明确指定的排序。
2. 缓存命中后的补图：恢复媒体信息 JSON 后原来提前返回，缺少主图也不会截图；正常提取模式现在继续生成缺失主图，纯恢复模式仍不启动截图。
3. 工作节点拒绝状态：使用 Emby 原生安全异常，越界和禁用状态返回 403，避免伪装成服务器内部故障。
4. 失效媒体库范围：保存时全部失效的选择不再被清空成“全部”，显示为“不处理任何媒体库”；查询和后台范围同步避免扩大到全库。

143 项隔离 Emby 回归通过，包含真实 HTTP 排序、真实 FFmpeg 缓存命中补图、403 和失效范围检查。新代码尚未加载到用户服务器，必须更换 DLL 并重启后复测。不能把这些本地检查表述为线上已生效。

## 尚无在线验收条件

当前媒体清单没有音乐、ISO/DVD 或 STRM 测试条目；没有豆瓣编号，本地元数据模式关闭，未配置第二工作节点。在线字幕下载、外部通知、IntroDB 外部真实数据和客户端实际播放没有完成端到端验收。不得据此宣称全部目标功能完成；远程 HTTP ISO/DVD 等原有未完成项不变。

原生内嵌封面格式异常仍可能让 Emby 自带截图提供器失败，本次只修正本插件缓存命中后的补图流程，没有修改 Emby 原生提供器。
