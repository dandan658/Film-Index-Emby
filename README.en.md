# Film Index Emby

Independent GPL community derivative targeting Emby 4.10.1.0. Current release is v0.1.0-preview.1 for user testing, not complete feature parity or certified fnOS/Linux support.

See [Chinese README](README.md), [installation and rollback](packaging/INSTALL.zh-CN.md), [development status](DEVELOPMENT.md), and [verification](VERIFICATION.json). The installation ZIP contains only the production DLL and installation tutorial. The tutorial includes notices, licenses, the DLL checksum and a corresponding-source link. No Emby server assemblies or test plugin are distributed.

The original upstream English introduction is preserved in [docs](docs/UPSTREAM-README.en.md); its feature list is not a supported-feature claim for this derivative.
